# 设置页验收清单（给 Claude Opus 审）

## 待审内容
- 新设置信息架构：常规 / 个性化 / 调校 / 服务 / 更新 / 关于
- 常规：语言、开机启动、总在最前、特殊键唤醒、电源配置（电池/电源各5档）、USB关机通电、电池充电限制
- 个性化：主题（外观模式/窗口风格/材质/颜色）、界面（状态条/GPU栏/刷新率栏/小组件栏，均可开关）

## 审的时候重点看
1. 区块顺序是否符合「常用在前、危险在后」的直觉
2. 每个开关的文案是否说清了「开了会发生什么」
3. 电源配置的电池/电源两级是否容易混淆
4. 电池充电限制的开关+进度条是否语义清楚（80% 到底是限充还是当前电量）
5. 危险项（服务、电源模式）有没有足够的护栏和确认
6. 有没有重复设置项、或者同一件事两个入口
7. 空状态/未实现项是怎么表现的
8. 新手第一次打开设置会不会迷路
