# Predex 设置信息架构重设计

## 0. 设计规则

后面的所有决定都从这四条规则推出来。

1. **功能和偏好分开放。** 会实时改变硬件状态、玩家会反复调的东西算「功能」，放在首页、快捷栏和「全部功能」里。设一次就很少再动的东西算「偏好」，放在设置（齿轮）里。
2. **一个东西只有一个家。** 风扇、灯光、浮窗、调校这些功能页只存在于功能体系，设置里不再放它们的入口。快捷栏只是指向功能页的快捷方式，不算第二个家。
3. **最多两层。** 首页（第一层）→ 功能页或设置页（第二层）→ 极少数编辑页（第三层，只有单键灯光会用到）。
4. **行名用玩家的话，术语放到副标题里。** 例如行名写「充电上限保护」，副标题写「限制在 80%，长期插电可延长电池寿命」。

### 命名对照

| 原名 | 新名 | 理由 |
|---|---|---|
| 电池限充 | 充电上限保护 | 说清楚它保护的是什么 |
| USB关机充电 | 关机时 USB 供电 | 描述的是用户看到的效果 |
| GPU模式 | 显卡模式 | 玩家日常说「显卡」 |
| 刷新率 | 屏幕刷新率 | 不变，加上主语 |
| 电源档位 | Windows 电源计划 | 和系统里的叫法一致，避免和性能模式混淆 |
| 调校 | 进阶调校 | 名字本身提示有门槛 |
| 浮窗指标 | 游戏浮窗 | 按用途命名 |
| 风扇曲线 | 风扇 | 页面里包含曲线，入口名短一点 |

## 1. 目录树

```
首页
├─ 状态区：CPU/GPU 温度、两个风扇转速（只读）
├─ 性能模式：节能 / 静音 / 均衡 / 性能
├─ 狂暴（独立大按钮）
├─ 快捷栏（用户可编辑，默认 4 项 + 固定的「全部」）
└─ 右上角：齿轮 → 设置

全部功能（从快捷栏的「全部」进入，同时是快捷栏的入口目录）
├─ 风扇
├─ 灯光
│   └─ 单键编辑（第三层，仅支持单键 RGB 的机型）
├─ 游戏浮窗
├─ 显卡与屏幕（显卡模式、屏幕刷新率）
└─ 进阶调校（CPU 调度、显卡超频）

设置（齿轮）
├─ 电池与供电
├─ 外观
├─ 语言（行内下拉，不进页）
├─ 开机启动（行内开关，不进页）
├─ 快捷栏
├─ 高级（后台服务、重置）
└─ 更新与关于
```

**为什么狂暴单独做按钮，不做成第五个分段：** 狂暴对应机身上的 Turbo 键，是一种临时进入、用完退出的状态。做成独立按钮后，关闭狂暴会自动回到之前的模式，玩家不用记住自己原来开的是哪个。320 DIP 放 5 段也勉强放得下，但那样狂暴和其他模式地位相同，退出时还得自己选回去。

## 3. 快捷栏编辑交互

### 入口目录：唯一的来源

做一份「功能注册表」，首页快捷栏、「全部功能」页、编辑态的添加列表都从这份表读取。每一项记录以下内容：

- 名称、图标、一句话说明
- 类型：
  - **页面型**：点击后打开对应的功能页，例如风扇、灯光。
  - **开关型**：点击直接切换，磁贴本身显示当前状态，例如刷新率 60/165、浮窗显示、键盘灯开关、充电上限保护。
- 硬件可用性：当前机型不支持的项不出现在任何地方。
- 能否加入快捷栏：进阶调校和停用 Acer 服务不允许加入。危险操作不应该一点就生效。

### 默认四项

| 位置 | 项 | 类型 | 理由 |
|---|---|---|---|
| 1 | 风扇 | 页面型 | 温度和转速已经在首页显示，调曲线是下一步最常做的事 |
| 2 | 屏幕刷新率 | 开关型 | 插电和用电池时频繁切换，一点就切最省事 |
| 3 | 游戏浮窗 | 开关型 | 进游戏前开、出游戏后关 |
| 4 | 灯光 | 页面型 | |

第 4 项之后固定跟一个「全部」磁贴。它不能删除，也不能移动，保证用户把快捷栏删空以后仍然能找到所有功能。

### 容量

每行 4 格，最多 2 行，也就是 8 项，外加「全部」。超过一行时首页增加约 72 DIP 高度。8 项是上限，再多快捷栏就失去了「快」的意义，剩下的功能留在「全部功能」里。

### 进入编辑态

以下三种方式效果相同：

- 长按任意磁贴，或在磁贴上右键选择「编辑快捷栏」。
- 在「全部功能」页点右上角的「编辑」。
- 在设置 → 快捷栏里点「编辑快捷栏」。

进入编辑态后：页面其他区域变暗且不可点击，快捷栏上方出现提示「拖动排序，点 − 移除」，页头的齿轮换成「完成」按钮。

### 删除

每个磁贴右上角出现 − 号，点一下立即移除，底部弹出提示「已移除 风扇 · 撤销」，持续 5 秒。删除不弹确认对话框，因为随时可以加回来。

### 添加

快捷栏末尾出现一个虚线框的 + 格。点击后从底部弹出添加列表，按「页面」和「开关」两组列出注册表中还没加入的项，每项带一句说明。点一项就加入到末尾。达到 8 项时 + 格消失，并提示「最多 8 项」。

### 排序

- 鼠标或触摸：拖动磁贴。
- 键盘：Tab 选中磁贴，Alt + ←/→ 移动位置，Delete 移除。
- 读屏：每个磁贴提供「左移」「右移」「移除」的辅助操作。

拖动不能是唯一的排序方式。

### 保存与退出

每一步修改即时保存。点「完成」、按 Esc 或点击快捷栏以外的区域，都会退出编辑态。不提供「取消全部修改」，单步撤销和「恢复默认快捷栏」已经足够。

## 4. 取舍

### 要不要设置搜索？不要

- 设置一级页只有 7 行，所有设置页加起来大约 30 个控件，用户扫一眼就能找到。
- 一个搜索框要占 48 DIP，相当于 520 DIP 高度里的一行，还需要长期维护同义词。比如用户可能搜「涡轮」「Turbo」「狂暴」，都得能搜到同一个东西。
- 替代做法：每个导航行的副标题显示当前值，「全部功能」页给每项写一句说明。
- 什么时候重新考虑：设置项超过 40 个，或者用户反馈里反复出现「找不到某个设置」。

### 要不要重置某项或全部？只在三处做单项重置，全部重置放进高级

- **单项重置**只做在用户确实可能调乱、而且自己恢复不回来的地方：风扇曲线、显卡偏移、快捷栏。开关和下拉不需要重置按钮，再点一下就回去了。每行都加重置会让界面翻倍地乱。
- **全部重置**放在「高级」里。确认对话框要写清楚会重置哪些内容，并说明哪些不受影响：显卡模式和 Windows 电源计划属于系统状态，不在重置范围内，避免重置后还要重启电脑。

### 危险项怎么呈现？按后果分三级

| 等级 | 项 | 后果 | 呈现方式 |
|---|---|---|---|
| 1 可撤销 | 恢复默认风扇曲线、恢复默认快捷栏 | 丢失自定义配置 | 页底的文字按钮，不弹确认。执行后给出 10 秒「撤销」，期间保留旧曲线 |
| 2 影响稳定 | 应用显卡偏移 | 可能花屏、驱动崩溃 | 应用后弹出「保持这个设置吗？」，15 秒倒计时，不点确认就自动回滚。和 Windows 修改分辨率的做法一样，即使画面坏了用户也不用操作。「开机自动应用」默认关闭，防止开机就崩溃。滑块范围限制在安全范围内 |
| 3 影响系统 | 停用 Acer 服务 | 狂暴键、部分风扇控制等功能可能失效 | 只放在「高级」页底部的「危险操作」区，用红色文字按钮。对话框列出具体会失效的功能，需要管理员权限。同一位置提供「恢复 Acer 服务」，并显示当前服务状态 |

所有危险项都不允许加入快捷栏，也不出现在首页。

### 关于要不要独立页？不要单独做一级页

和「更新」合并成「更新与关于」。设置列表里这一行的副标题直接显示版本号和更新状态，大多数用户不用点进去。点进去的通常是来反馈问题的人，所以页内放机型、BIOS、EC 版本和复制按钮，方便用户贴到反馈里。

## 5. 落地顺序与不该做的事

### 落地顺序

1. **建立功能注册表。** 这是快捷栏、全部功能页和添加列表共用的数据来源，后面每一步都依赖它，还能顺手按机型过滤掉不支持的功能。
2. **首页改造。** 先上线固定的默认四项加「全部」，同时把灯光、浮窗、风扇、调校从设置里移出去。这一步先解决「入口重复」，即使编辑态还没做，问题也已经消失了。
3. **设置瘦身和重新分组。** 改成 7 行结构，换上新的命名，导航行加上显示当前值的副标题。老用户的设置值原样迁移，旧的首页底栏配置映射成快捷栏初始内容。
4. **快捷栏编辑态。** 包括删除、添加、拖动排序和键盘排序。
5. **危险项分级。** 显卡偏移的自动回滚、风扇曲线的撤销、停用服务的后果说明。
6. **验收。** 检查 200% 缩放、键盘操作、讲述人朗读，以及英文等较长语言在 320 DIP 宽度下行名和副标题是否被截断。

### 不该做的事

- 不要让同一个功能出现在两个家里，例如在设置里再放一个「风扇」入口。
- 不要往首页加更多实时控件。首页只服务三件高频的事：切模式、看温度转速、开狂暴。
- 不要切换性能模式时弹确认，这是最高频的操作。
- 不要用 TDP、PL1、EC 这类术语当行名。需要的话放在副标题或说明里。
