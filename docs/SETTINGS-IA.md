# 设置信息架构（IA）规划 · 待确认

> 目标：把散落的功能收进「设置」，把灯光/浮窗/风扇/调校降级为**快捷入口**（不再是并列的一级导航）。
> 约束：单窗口 320 DIP 宽、二级页最高 520 DIP（内容超出页内滚动）、已有「页 + 返回」导航。

---

## 1. 现在的导航（要改的现状）

```
首页 Home
 ├ 灯光 Lighting        ← 现在是一级页（首页底部图标直达）
 ├ 浮窗 Overlay         ← 一级页
 ├ 风扇 Fans            ← 一级页
 ├ 调校 Tuning          ← 一级页
 └ 设置 Settings         ← 一级页（里面混着 语言/主题/启动/Acer服务/电池/USB/电源配置）
```
问题：设置里混了两类东西（**偏好** 和 **功能入口**），而功能入口又在首页和设置里各出现一次，重复。

---

## 2. 建议的目标结构

```
首页 Home（折叠态只有模式；展开态有模式 + GPU + 刷新率 + 底部入口）
 │
 └ 设置 Settings（设置首页 = 目录页，只有一行行条目）
     ├ 常规            General     语言 / 开机启动 / 关闭行为 / 托盘
     ├ 电源配置        Power       电池限充 / USB 关机充电 / 电池档位 / 交流档位
     ├ 主题            Appearance  深色·浅色·跟随系统 / 圆角风格 / 材质 / 强调色
     ├ 设备与性能       Devices     ← 四个「快捷入口」收在这里
     │   ├ 灯光 Lighting
     │   ├ 浮窗 Overlay
     │   ├ 风扇 Fans
     │   └ 调校 Tuning
     ├ 更新            Update      检查更新 / 通道 / 下载进度
     └ 关于            About       版本 0.1.0-alpha.1 / 日志 / 许可证
```

### 为什么这么分
- **偏好（常规/电源/主题/关于）** 是「一次设完就不动」的，放在一起；
- **设备与性能** 是「天天要看要调」的，单独成组，且作为快捷入口保留原有四个页面；
- **更新** 与 **关于** 分开：更新是有状态的（检查中/有新版/下载中），关于是只读信息。

---

## 3. 三种可选落法（选一个）

| 方案 | 设置首页长什么样 | 优点 | 缺点 |
|---|---|---|---|
| **A. 目录页 + 逐级返回**（我推荐） | 设置首页是一列分组条目（每组一个小标题 + 若干行，右侧 `›`），点进去是二级页，返回回目录 | 320 DIP 最合适；每页内容少、不滚；和现有「页+返回」机制一致 | 层级多一层（设置 → 常规） |
| B. 设置内左侧导航 | 设置页内再切分左右（左窄栏 96 DIP + 右内容） | 少点一次返回 | 320 DIP 下右内容只剩 ~210 DIP，滑动条/数值框会挤；不推荐 |
| C. 设置首页 = 全部设置平铺 + 折叠分组 `Expander` | 一页装下所有偏好，设备入口放最上面 | 一次能看到全部 | 现在 7 组 × 平均 5 行 ≈ 35 行，必然超 520 DIP 要滚很久；而且和「二级菜单」的要求冲突 |

推荐 **A**。

## 5. 首页要不要保留那四个快捷图标？

| 选项 | 说明 |
|---|---|
| **A. 保留**（推荐） | 展开态底部那排 `灯光/浮窗/风扇/调校` 继续留在首页，同时设置里也有一份。日常高频访问不用先进设置 |
| B. 只留设置 | 首页展开态底部那排删掉，统一从设置进。少一行，但每次要多点两次 |
| C. 首页留两个常用（风扇/调校），灯光/浮窗进设置 | 折中 |

推荐 A，理由：用户原话是「本质上是快捷方式」——那就让它真的是快捷方式，而不是唯一入口。

## 6. 风险 / 要先定的点

1. **「Acer 后台服务」省内存开关会停 `PSSvc`**，而 `PSSvc` 是传感器与模式切换的命脉（实测：停了它，切模式必失败、温度读数走 ACPI 回退）。这个开关要么**加硬保护**（不允许停 PSSvc），要么至少加红色警告 + 二次确认。
2. **设置首页会有 6 组条目**，320 DIP 宽下一屏能不能放下？按 6 组 × (小标题 20 + 行 36) ≈ 336 DIP，可以，但要实测。
3. **二级页返回栈**：从「设置 → 设备与性能 → 风扇」再返回，应该回到「设备与性能」还是直接回「设置」？建议**逐级返回**（符合目录页的心智）。
4. **主题页要立即生效**（不点应用），但「窗口风格」切直角/圆角会重建 DWM 圆角，需要注意切换时窗口不闪。

---

## 7. 落地顺序（建议）

1. 先落 **IA 骨架**：设置首页做成目录页（6 组条目 + `›`），现有设置项按 §4 拆到 常规/电源 两页；主题页已有独立页可直接挂上；更新/关于先放占位页。
2. 再把 `灯光/浮窗/风扇/调校` 挂进「设备与性能」（不新增页面，只加路由）。
3. 最后做 **更新页**（接 `UPDATE-DESIGN.md` 的方案）+ 关于页。
